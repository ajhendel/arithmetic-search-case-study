# v1.0.0 — archival release

Released 2026-09-05. The repository is public and its Zenodo integration is
enabled. Zenodo assigns this artifact its own DOI when processing the release.

This snapshot closes the evo608 candidate investigation. It retains the verified
candidate and ablation, the stronger bounded UFO-MAC-derived controls, exact
contracts, proof tools, selected raw evidence, and a short negative-result report.

The source research revision is recorded in SOURCE_MANIFEST.json. The snapshot
starts a new public-facing history instead of exposing the entire exploratory
repository. Original code identities, source hashes, licenses, and author credit
are retained. Local build artifacts, PDKs, large layout databases, unrelated
research targets, and the unfinished manuscript are omitted.

Measured takeaway: the stronger default-flow comparator is 8.13% faster and
0.21% smaller than evo608, removing its earlier finite-set frontier claim.
No new measurements were run to prepare this archival release.

There is no scheduled development or maintenance commitment. The scripts can
support independent follow-up, but their presence is not a promise of further
experiments by the author.
